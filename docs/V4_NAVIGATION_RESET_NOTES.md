# WareWise XR v4 — Navigation, Signage and Reset

This revision addresses usability issues found during hands-on testing of the v3 training floor.

## Changes

- Added a persistent warehouse minimap showing the trainee, major training stations, unresolved hazards and the current objective.
- Added a live objective compass arrow and distance readout.
- Added desktop world-space station labels that appear while facing nearby stations.
- Added true 3D block-letter signs for BRIEF, CYBER, 5 WHYS, DUEL, HEIGHT, MANUAL and RECEIVE so station identification remains visible in VR.
- Clustered freely movable practice objects around the front manual-handling area.
- Moved Cyber Awareness to the front training area and moved 5 Whys / Hazard Duel from the far loading end into the mid-warehouse.
- Added **Reset warehouse** to the live HUD and shift menu. It clears trainee score/progress, resets hazards/challenges, restores moved objects, rebuilds the original scene and returns the camera to the start.
- Corrected horizontal mouse/touch look direction. Right turns right; left turns left. Vertical look remains direct: up looks up and down looks down.

## New-trainee handover

At the end of a training session, select **Reset warehouse** and confirm. The simulation is reconstructed in place and is ready for another trainee without manually replacing crates, hazards or props.
